# News Catch

[English](README.md) | [简体中文](README.zh-CN.md)

运行在本地浏览器中的新闻采集、筛选、AI 分析、人工审核和 Webhook 推送工作台，可配置分类引擎适用于不同行业与研究主题。Python 后端、原生 HTML/CSS/JavaScript 前端、SQLite 本地存储。

目前工具界面使用简体中文。

## 初始状态

不预置新闻源、关键词规则、目标区域、模型地址/名称/密钥、Webhook 或字段映射；不携带原用户新闻、原文、推送记录、数据库或内部任务文档。首次使用需自行配置。

默认通用分类包括产品与服务、技术与创新、市场与经营、政策与监管、组织与合作、风险与事件、其他。可在网页配置分类名称、说明、关键词、建议动作以及地区名称和别名；不再限定车载语音主题、固定公司清单或原有五分类映射。

## 功能

- RSS / 网页来源管理，OPML 批量导入、来源连通测试及健康状态。
- 网页正文抓取、人工原文补充，关键词布尔表达式筛选、去重、区域/类别判定。
- 可配置 OpenAI 兼容模型 API，单条与批量后台分析、长正文分段、证据校验及中文摘要。
- 行业背景、分类体系、建议动作、优先词、排除词和地区均可配置，审核选项与 Webhook 输出跟随配置。
- 人工编辑审核、待推送队列、退回重审、软删除与恢复。
- Webhook 字段新增/删除/映射，可编辑 JSON 预览、失败重试及推送历史。
- 网页快照变化跟踪、运行概览、定时任务、Markdown 周报。

## Windows 启动

1. 安装 **Python 3.11 或更新版本**，安装时启用 Python Launcher 或加入 `PATH`。
2. 下载并完整解压本仓库，双击 **start.cmd**。首次联网创建 `.venv` 并安装锁定依赖；后续使用本地环境启动。
3. 浏览器自动打开工作台。在「分析与分类」设置行业或主题、业务背景、分类及建议动作并保存，之后可随时修改。
4. 在「来源与规则」添加来源（也可导入 OPML）、新增命名规则并填写表达式，再保存。表达式支持 `AND`、`OR`、`NOT`、括号和双引号短语；规则为空时普通新闻不入池。
5. 在「模型与 Webhook」填写服务地址、模型名、密钥及自己的 Webhook；用「新增字段」配置接收字段映射。存在待推送新闻但未配置任何映射时，会阻止推送。
6. 点击「立即运行」，按需抓取正文、分析、审核、预览和推送。

首次安装需要能访问 Python 包源，采集和模型调用需要相应网络及接口权限。本源码版不附带 Python 或预设账号。若系统 Python 升级，请删除本项目 `.venv` 后重新启动以重建环境。

## 配置通用分类引擎

例如关注医疗健康，可以将行业设为医疗健康，在背景中写清团队关注哪些变化，再定义临床研究、产品器械、政策监管等分类，为每类填写判定说明与关键词。关注零售消费时，改为相应的分类及建议动作即可，无需修改源码。

「分析与分类」管理分析档案：建议动作、优先关注关键词和排除关键词均为每行一项；地区定义使用 `名称 | 别名,别名`，每行一个地区。「来源与规则」中勾选的目标区域仍是独立的采集过滤条件，不勾选时不限制地区。普通新闻是否入池由布尔筛选规则决定，优先词用于候选排序，排除词剔除不需要的匹配内容。

模型按照已保存的行业背景和分类说明分析，并提供原文逐字证据；类别与建议动作从配置中选择。没有可用模型结果且无法匹配分类时，记录保留为「未分类」及待审核，不凭空判定。保存分析配置影响后续采集和分析，不改写已有新闻或历史推送；旧记录原有类别、建议动作仍可在审核时查看。

Webhook 的 `category`、`company` 保留分析或人工编辑后的内容，不再转为某个行业的固定清单。`language` 支持任意语言名称，多个值拆为数组输出。地区仍输出单个选项字符串，接收表格应设置对应选项；字段映射及类型转换按自己的表格结构配置。

为兼容已有记录，阶段仍保存为「仅宣布 / 测试中 / 灰度 / 已上线 / 待确认」，分别表示宣布或计划、试验或试点、分批实施、已实施或已生效、未明确；具体业务里程碑写入核心变化。分析期间修改分类配置会阻止旧分析结果覆盖现有内容。更新详情见 [CHANGELOG.md](CHANGELOG.md)。

## 手动启动 / Linux / macOS

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -B launch.py
```

Windows 对应使用 `.venv\Scripts\python.exe`。主要业务逻辑跨平台，当前分发仅在 Windows x64 / Python 3.11 环境验证；未实测 Linux 和 macOS。

启动器默认只监听 `127.0.0.1`，自动选择 4173–4192 中的空闲端口；可以传入 `--port 4216`、`--no-browser` 或 `--no-scheduler`。关闭终端后服务和定时任务停止，电脑休眠期间不会执行。时间设置按 Asia/Shanghai（GMT+8），默认 10:00，启动晚于计划时间可能补执行。

## 检查与测试

安装依赖后，Windows 使用虚拟环境检查及测试：

```powershell
.\.venv\Scripts\python.exe -B launch.py --check
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v
```

Linux / macOS 对应使用 `.venv/bin/python`。

`--check` 使用临时数据检查依赖和空默认配置，不访问模型/Webhook；测试使用隔离目录与模拟响应。可用 `--data-dir` 指定独立数据目录。

## 数据与共享

运行后 `workbench/data/config.json` 保存个人配置（包含密钥和 Webhook），`workbench/data/trenddesk.sqlite3` 保存新闻及历史；需妥善保管。停止服务后备份整个 `workbench/data`。

## 当前边界

网页抽取无法保证访问需登录、限制自动抓取或仅通过前端脚本动态渲染的内容，可改用人工原文。AI 输出需要人工核验。

当前无多人账号权限与公网部署加固，适合本机运行；云端协作需要另行改造。Webhook 是否写入成功由接收方返回与字段类型决定。
